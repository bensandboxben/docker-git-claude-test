# Project Instructions

This is a test PHP website using Docker, GitHub and Claude Code.

## Technology
- PHP 8.4
- Apache
- Docker Compose
- HTML and CSS

## Development rules
- Keep the application simple.
- Use modern PHP practices.
- Keep HTML accessible.
- Use semantic HTML.
- Keep CSS organised.
- Do not introduce unnecessary dependencies.
- Do not change Docker configuration without explaining why.
- Do not commit secrets or credentials.

## Testing
- The application runs at http://localhost:8080
- Use Docker Compose to build and run the application.
- Check PHP syntax before committing changes.
